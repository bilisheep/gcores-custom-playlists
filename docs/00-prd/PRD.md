# 产品需求文档

- 适用版本：v0.8.0
- 需求基线：已验收

## 用户痛点

用户无法依赖机核原生队列长期维护多个播单，也无法在机核现有播单页面优先浏览自己的播单、用封面区分主题，或把某位主播参与的节目一次收集、按播单恢复断点并分享给其他脚本用户。

## 用户角色

- 播单创建者：安装脚本并管理、播放和分享播单。
- 播单接收者：已安装脚本，通过二维码或链接导入播单。
- 会员内容用户：已登录机核且具备对应节目访问权限。
- 扩展用户：使用 Chrome 或 Edge，从 GitHub Release 下载并加载扩展，使用独立本地数据。

## 使用场景

- 从节目列表逐期整理主题播单。
- 在用户页批量收集某位 DJ/主播参与的全部公开节目。
- 中断收听后从同一播单断点继续。
- 通过二维码将播单分享给另一浏览器或其他用户。
- 在机核官方播单页面切换“我的 / 机核 / 入驻”，并以相同卡片形式选择本地播单。
- 为播单选择本地图片作为封面，或恢复自动封面。
- 从 GitHub Release 下载同一 Chromium ZIP，在 Chrome 或 Edge 开发者模式加载扩展。

## 产品流程

安装脚本 → 打开官方播单页面并默认进入“我的” → 选择或创建播单并按需设置封面 → 添加节目或批量加入 → 使用底部播放器收听 → 自动保存断点 → 管理或分享播单 → 接收者确认导入。

## 功能模块

- 播单与节目管理
- 独立播放器与断点
- 用户参与节目批量加入
- 二维码分享与导入
- 专辑批量加入
- 官方播单页本地分类与封面
- 本地持久化与多标签协调
- Chrome/Edge 扩展打包与 GitHub Release

## 需求详情

### REQ-PLAYLIST-001 多播单管理

- 状态：已实现
- 目标/价值：允许用户创建、选择、改名和删除多个独立播单。
- 正常行为：每个播单保存自己的节目顺序和断点。
- 异常与权限：删除前必须由用户确认；至少保留一个可用播单。
- 验收条件：AC-PLAYLIST-001。

### REQ-ITEM-001 节目添加、删除与排序

- 状态：已实现
- 正常行为：节目卡片旁提供区别于官方加号的“列表＋”按钮；播单内支持播放、移除、上移和下移。
- 业务规则：同一播单内按节目 ID 去重。
- 验收条件：AC-ITEM-001。

### REQ-PLAYER-001 独立网页播放器

- 状态：已实现
- 正常行为：底部居中播放器显示封面和节目名；主行提供播放/暂停、下一期和单一音量图标；第二行显示当前时间、可拖动进度和总时长；点击音量图标显示竖直轨道并可上下拖动；点击封面进入对应节目详情，点击标题/播单信息进入所属本地播单的完整详情页。
- 进度规则：已加载节目拖动时直接 seek 并在释放时保存；未加载但存在播单断点时显示已保存位置但禁用拖动；无节目、加载中、错误或无有效时长时禁用进度。
- 音量规则：点击图标开关弹层；使用原生竖向 range，向上增大、向下减小；拖动时实时生效，释放时持久化；支持方向键、Home 和 End；点击外部或按 Esc 关闭。
- 异常行为：加载时禁用播放，失败后显示可重试状态；原生媒体播放时暂停自定义音频。
- 验收条件：AC-PLAYER-001。

### REQ-PROGRESS-001 播单级断点续播

- 状态：已实现
- 业务规则：每个播单只保存当前节目 ID、秒级位置和更新时间；节目完成后断点回到首期零秒。
- 验收条件：AC-PROGRESS-001。

### REQ-USER-001 用户参与节目批量加入

- 状态：已实现
- 正常行为：在用户页查询该用户作为 DJ 参与的公开节目，遍历全部分页后原子写入点击时的当前播单。
- 业务规则：保持接口顺序、跨分页去重、跳过播单已有节目；任一分页请求失败时不写入部分结果。
- 验收条件：AC-USER-001。

### REQ-SHARE-001 二维码分享与导入

- 状态：已实现
- 正常行为：二维码和链接只编码播单名与节目 ID；接收者确认后查询最新节目资料并建立新播单。
- 业务规则：最多 200 期且链接不超过 2800 字节；不分享进度或授权地址。
- 验收条件：AC-SHARE-001。

### REQ-SYNC-001 多标签页协调

- 状态：已实现
- 正常行为：播单与音量变化跨标签同步；新标签开始播放时旧标签暂停或取消加载。
- 验收条件：AC-SYNC-001。

### REQ-DANMAKU-001 时间轴时刻评论弹幕

- 状态：已实现
- 目标/价值：让官方全屏时间轴中的播放时刻与评论区讨论同步出现，提高共同收听感和时间轴信息密度。
- 角色与前置条件：用户打开非 FM 节目的官方全屏时间轴；页面存在官方音频元素和时间轴容器。
- 输入与输出：输入为机核 `filter[timed]=1` 的公开评论及其 `radio-timestamp` 秒数；输出为时间轴区域内从右向左移动的评论正文。
- 正常行为：分页获取全部时刻评论；按 `radio-timestamp` 排序；经过对应时间时进入最多 4 条轨道，约 8 秒完成移动；评论正文移除开头时间文本并最多显示 80 个 Unicode 字符；开关状态保存在本地。
- 业务规则：使用“上次进度 < 评论时刻 ≤ 当前进度”触发；轨道满时丢弃而非排队；同一评论在同一次正向经过中只显示一次。
- 异常与权限：暂停冻结动画；继续恢复；seek 清空当前弹幕并重设游标，不补发跳过区间；向后 seek 后再次经过可重播；API 或 DOM 不可用时静默停用且不影响播放器。
- 可访问性：`prefers-reduced-motion: reduce` 时不横向移动，改为时间轴顶部短暂静态显示。
- 非范围：自定义底部播放器弹幕、弹幕发送、颜色/速度/字号配置、评论持久缓存。
- 验收条件：AC-DANMAKU-001。

### REQ-ALBUM-001 专辑节目一键加入

- 状态：已验收
- 正常行为：在 `content-type=radio` 的机核专辑页“播放全部”旁显示“加入当前播单”；根据专辑免费属性选择 `published-radios` 或 `published-audiobooks`，遍历全部分页并按接口官方顺序追加。
- 业务规则：只接受 `radios`；按节目 ID 去重；加载时禁用按钮；全部分页成功后一次写入；付费节目允许加入但播放时仍执行现有账号权限校验；视频专辑不显示按钮。
- 异常行为：任一分页失败、重复分页、数量不完整或目标播单被删除时不写入部分结果；重复点击保持幂等。
- 验收条件：AC-ALBUM-001。

### REQ-ORDER-001 播单正序/倒序播放

- 状态：已验收
- 正常行为：“正序”按播单当前规范顺序播放，“倒序”按其反向播放；切换只保存每个播单的 `direction`，不物理反转节目数据。
- 业务规则：当前节目和断点不因切换方向改变；上一期、下一期、自然播完和无断点起点都遵循当前方向；倒序下新增节目显示在前端起点；手动上下移动按可见方向生效。
- 分享规则：二维码按当前可见顺序分享，但接收者新播单默认正序。
- 验收条件：AC-ORDER-001。

### REQ-LIBRARY-001 左栏播单库与自定义封面

- 状态：已替代
- 目标/价值：让用户从机核全站左栏快速进入自己的播单库，并用封面识别不同主题播单。
- 角色与前置条件：已安装脚本；页面存在机核左侧导航；Tampermonkey 存储中至少存在一个播单。
- 输入与输出：输入为用户选择的本地图片；输出为仅保存在本机的正方形压缩封面，以及展示全部已保存播单的封面卡片库。
- 正常行为：在官方“播单”入口下方新增同风格“我的播单”；点击打开播单库，卡片显示封面、名称、节目数和当前播单状态；点击卡片选择播单并进入现有管理面板；卡片附近可设置、更换或移除封面。
- 业务规则：旧数据无损补齐空封面；无自定义封面时使用当前可见首期节目的封面，再无节目时显示音乐占位图；图片在浏览器内居中裁成 1:1、缩放压缩并限制体积；封面不进入二维码或分享链接；新建和导入播单默认无自定义封面。
- 异常与权限：左栏或官方入口不存在时静默不挂载；SPA 重绘不得重复入口；无效、无法解码或过大的图片不写入并显示错误；异步处理期间播单被删除时放弃写入；封面变化继续参与多标签页同步。
- 优先级：P1
- 版本范围：v0.7+
- 验收条件：AC-LIBRARY-001。
- 关联设计/任务/测试：`docs/01-design/project-design.md`、TASK-007、AC-LIBRARY-001。
- 替代关系：由 REQ-CATALOG-001 替代；用户取消额外左栏入口和弹窗/独立库，改为集成官方播单页面。

### REQ-CATALOG-001 官方播单页本地分类与封面

- 状态：已验收
- 目标/价值：让本地播单与机核官方播单处在同一页面和视觉体系中，同时明确区分本地数据与官方数据。
- 角色与前置条件：已安装油猴版或扩展版；用户打开 `/albums`；当前分发方式的浏览器本地存储中至少存在一个播单。
- 输入与输出：输入为本地播单状态和用户选择的本地图片；输出为官方播单页面顶部的“我的 / 机核 / 入驻”切换、本地播单卡片及完整本地详情页。
- 正常行为：`/albums` 无官方 filter 时默认展示“我的”，“我的”位于“机核 / 入驻”之前；本地卡片沿用官方播单卡片网格、封面比例和排版，仅通过轻量“自建”标识区分；点击卡片在同一主内容区进入完整详情，支持返回、刷新和浏览器历史；底栏标题进入所属本地播单详情；`filter=gcores` 与 `filter=join` 完全保留官方内容和分页。
- 业务规则：本地数据只写入当前油猴或扩展的本地存储适配，不调用机核写接口；旧数据无损补齐空封面；无自定义封面时使用当前可见首期节目封面，再无节目时显示音乐占位图；图片在浏览器内居中裁成 1:1、缩放压缩并限制体积；封面不进入二维码或分享链接；新建和导入播单默认无自定义封面。
- 异常与权限：官方播单页结构不存在时静默停用且不破坏原页面；SPA/React 重绘不得重复页签或永久隐藏官方内容；无效、无法解码或过大的图片不写入并显示错误；详情 ID 无效或已删除时返回“我的”；封面变化继续参与多标签页同步。
- 优先级：P1
- 版本范围：v0.7+
- 验收条件：AC-CATALOG-001。
- 关联设计/任务/测试：`docs/01-design/project-design.md`、TASK-008、AC-CATALOG-001。

### REQ-EXTENSION-001 Chrome/Edge 扩展与 Release

- 状态：已验收
- 目标/价值：让不使用 Tampermonkey 的 Chrome/Edge 用户通过标准 Chromium 扩展获得同一套机核自定义播单能力。
- 角色与前置条件：用户使用 Chrome 或 Edge，并能开启扩展开发者模式、加载已解压扩展。
- 输入与输出：输入为当前单文件业务脚本；输出为 Manifest V3 解压目录、Chrome/Edge 共用 ZIP、SHA-256 和 GitHub Release。
- 正常行为：扩展只在 `https://www.gcores.com/*` 运行；首次安装为空播单；使用 `chrome.storage.local` 保存播单、封面、断点、音量和弹幕开关；多标签监听保持现有 remote 语义；功能与同版本油猴脚本一致。
- 业务规则：油猴脚本仍是唯一业务源码，扩展内容脚本由无依赖构建脚本生成；只申请 `storage`、`unlimitedStorage` 和机核站点范围；无后台页、弹窗、远程代码、遥测或第三方依赖；扩展和 Tampermonkey 不应同时启用。
- 异常与权限：扩展存储初始化完成前不得运行业务脚本；本标签写入不得被误判为远端变化；构建时 Manifest 与用户脚本版本不一致必须失败；发布 ZIP 只包含白名单文件；不迁移、读取或删除 Tampermonkey 旧数据。
- 优先级：P1
- 版本范围：v0.8+
- 验收条件：AC-EXTENSION-001。
- 关联设计/任务/测试：`docs/01-design/project-design.md`、TASK-009、AC-EXTENSION-001。

## 跨需求业务规则

- 所有持久化节目 ID 必须是 1–12 位数字。
- 所有第三方文本进入 `innerHTML` 前必须转义。
- 不调用机核写接口，不改变收藏、历史、评论或账号设置。

## 异常与权限规则

- 未登录或无权播放时显示明确错误，不绕过机核权限。
- API 返回异常分页、无效节目或重复整页时中止批量写入。
- 分享数据必须先通过长度、字符、版本和 ID 校验，再解码或导入。
- 自定义封面必须在写入前验证图片类型、输入体积、解码结果和压缩后长度。
- 弹幕只展示机核接口允许当前用户查看的公开时刻评论，不上传或长期保存评论正文。

## 延期、取消或替代项

- 自动更新、分片二维码、云端同步、封面分享、图片裁剪编辑器和拖拽排序未进入当前基线。

## 开放问题

- 机核未来页面或 API 变更时，兼容策略需要根据实际变化重新确认。
