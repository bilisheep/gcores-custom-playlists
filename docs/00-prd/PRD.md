# 产品需求文档

- 适用版本：v0.4.3
- 需求基线：已确认

## 用户痛点

用户无法依赖机核原生队列长期维护多个播单，也无法把某位主播参与的节目一次收集、按播单恢复断点或直接分享给其他脚本用户。

## 用户角色

- 播单创建者：安装脚本并管理、播放和分享播单。
- 播单接收者：已安装脚本，通过二维码或链接导入播单。
- 会员内容用户：已登录机核且具备对应节目访问权限。

## 使用场景

- 从节目列表逐期整理主题播单。
- 在用户页批量收集某位 DJ/主播参与的全部公开节目。
- 中断收听后从同一播单断点继续。
- 通过二维码将播单分享给另一浏览器或其他用户。

## 产品流程

安装脚本 → 创建或选择播单 → 添加节目或批量加入 → 使用底部播放器收听 → 自动保存断点 → 管理或分享播单 → 接收者确认导入。

## 功能模块

- 播单与节目管理
- 独立播放器与断点
- 用户参与节目批量加入
- 二维码分享与导入
- 本地持久化与多标签协调

## 需求详情

### REQ-PLAYLIST-001 多播单管理

- 状态：已实现
- 目标/价值：允许用户创建、选择、改名和删除多个独立播单。
- 正常行为：每个播单保存自己的节目顺序和断点。
- 异常与权限：删除前必须由用户确认；至少保留一个可用播单。
- 验收条件：AC-PLAYLIST-001。

### REQ-ITEM-001 节目添加、删除与排序

- 状态：已实现
- 正常行为：节目卡片旁提供区别于官方加号的“列表＋”按钮；播单内支持播放、移除、上移和下移。
- 业务规则：同一播单内按节目 ID 去重。
- 验收条件：AC-ITEM-001。

### REQ-PLAYER-001 独立网页播放器

- 状态：已实现
- 正常行为：底部居中播放器显示封面和节目名，提供播放/暂停、下一期和音量；点击左侧打开管理面板。
- 异常行为：加载时禁用播放，失败后显示可重试状态；原生媒体播放时暂停自定义音频。
- 验收条件：AC-PLAYER-001。

### REQ-PROGRESS-001 播单级断点续播

- 状态：已实现
- 业务规则：每个播单只保存当前节目 ID、秒级位置和更新时间；节目完成后断点回到首期零秒。
- 验收条件：AC-PROGRESS-001。

### REQ-USER-001 用户参与节目批量加入

- 状态：已实现
- 正常行为：在用户页查询该用户作为 DJ 参与的公开节目，遍历全部分页后原子写入点击时的当前播单。
- 业务规则：保持接口顺序、跨分页去重、跳过播单已有节目；任一分页请求失败时不写入部分结果。
- 验收条件：AC-USER-001。

### REQ-SHARE-001 二维码分享与导入

- 状态：已实现
- 正常行为：二维码和链接只编码播单名与节目 ID；接收者确认后查询最新节目资料并建立新播单。
- 业务规则：最多 200 期且链接不超过 2800 字节；不分享进度或授权地址。
- 验收条件：AC-SHARE-001。

### REQ-SYNC-001 多标签页协调

- 状态：已实现
- 正常行为：播单与音量变化跨标签同步；新标签开始播放时旧标签暂停或取消加载。
- 验收条件：AC-SYNC-001。

## 跨需求业务规则

- 所有持久化节目 ID 必须是 1–12 位数字。
- 所有第三方文本进入 `innerHTML` 前必须转义。
- 不调用机核写接口，不改变收藏、历史、评论或账号设置。

## 异常与权限规则

- 未登录或无权播放时显示明确错误，不绕过机核权限。
- API 返回异常分页、无效节目或重复整页时中止批量写入。
- 分享数据必须先通过长度、字符、版本和 ID 校验，再解码或导入。

## 延期、取消或替代项

- 自动更新、分片二维码、云端同步和拖拽排序未进入当前基线。

## 开放问题

- 机核未来页面或 API 变更时，兼容策略需要根据实际变化重新确认。
