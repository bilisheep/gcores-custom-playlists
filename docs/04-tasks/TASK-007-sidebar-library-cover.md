# TASK-007: 左栏播单库与自定义封面

- 状态：取消
- 目标与范围：在官方左栏“播单”下增加“我的播单”入口；增加显示全部本地播单的封面卡片库；允许本地图片设置、更换和移除播单封面，并与现有详情管理、多标签同步衔接。
- 非范围：封面随二维码或链接分享、上传图床、账号同步、图片裁剪编辑器、重做现有详情管理和播放器。

- 测试与验收：AC-LIBRARY-001；语法、自检、旧状态迁移、合法/无效/过大图片、设置/替换/移除、自动封面、库/详情往返、左栏重挂、跨标签同步、二维码载荷、键盘和减少动态效果。
