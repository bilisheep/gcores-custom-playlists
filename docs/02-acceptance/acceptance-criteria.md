## 非功能验收项

- 输入边界：分享 hash 在解码前限制长度和字符；节目 ID 校验为 1–12 位数字。
- 安全：不输出 Cookie、授权 URL 或个人账号资料；截图隐藏登录头像。
- 兼容：Chrome/Edge/Firefox/Safari 的 Tampermonkey 环境具备 `GM_*`、`fetch`、Shadow DOM 和 Audio。
- 可访问性：关键按钮有 aria-label/focus-visible，减少动态效果设置生效。
- 弹幕可访问性：减少动态效果模式下不产生横向移动；弹幕层不接收指针事件。
